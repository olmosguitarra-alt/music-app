### 1. OPACIDAD REAL AL 100% EN EL TRAZO LIBRE (CERO TRANSPARENCIA RESIDUAL)
- **Problema Actual:** Aunque la opacidad esté fijada al 100% (`brushOpacity = 1.0`), el trazo sigue mostrando transparencia o falta de cobertura sólida en el canvas.
- **Causa Raíz en `app.js`:**
  - En la función de renderizado de trazos (`applyStrokeStyle` o al rellenar la espina Bézier), se está aplicando mezcla de capas indebida o se atenúa el canal alfa:
    * Asegurar que para la pluma (`pen`):
      ```javascript
      ctx.globalCompositeOperation = "source-over";
      ctx.globalAlpha = Math.min(1.0, Math.max(0.1, stroke.opacity ?? 1.0));
      ```
    * Si la herramienta es pluma (`pen`) y la opacidad es 100%, la tinta debe ser **100% opaca y sólida** (cobertura total sobre el PDF y trazos previos).
    * Al rellenar los polígonos del trazo Bézier continuo, asegurar que el color RGB/Hexadecimal no tenga canales alfa reducidos en formato `rgba(...)`.

### 4. REPARACIÓN TOTAL DEL ARRASTRE FLOTANTE (ESTILO SIBELIUS)
- **Problema Actual:** La paleta flotante no se puede desplazar porque faltaba el ciclo completo de eventos de puntero (`pointerup` / `pointercancel`) o el `pointerdown` en la cabecera no propaga el desplazamiento al contenedor con estilo `fixed`.
- **Implementación Robusta del Arrastre:**
  ```javascript
  function initStampPaletteDrag() {
    const pop = document.getElementById("stampPopover");
    const header = document.getElementById("stampPaletteHeader");
    if (!pop || !header) return;

    let isDragging = false;
    let startX = 0, startY = 0;
    let initialLeft = 0, initialTop = 0;

    header.onpointerdown = (e) => {
      if (e.target.closest("button")) return; // permitir cerrar con la X
      isDragging = true;
      header.setPointerCapture(e.pointerId);

      const rect = pop.getBoundingClientRect();
      initialLeft = rect.left;
      initialTop = rect.top;
      startX = e.clientX;
      startY = e.clientY;
      e.preventDefault();
    };

    header.onpointermove = (e) => {
      if (!isDragging) return;
      const dx = e.clientX - startX;
      const dy = e.clientY - startY;
      
      const newX = Math.max(10, Math.min(window.innerWidth - pop.offsetWidth - 10, initialLeft + dx));
      const newY = Math.max(10, Math.min(window.innerHeight - pop.offsetHeight - 10, initialTop + dy));

      pop.style.left = `${newX}px`;
      pop.style.top = `${newY}px`;
      pop.style.right = "auto";
      pop.style.bottom = "auto";
      pop.style.transform = "none"; // Evita conflictos con translate3d
    };

    const stopDrag = (e) => {
      if (isDragging) {
        isDragging = false;
        try { header.releasePointerCapture(e.pointerId); } catch (_) {}
      }
    };

    header.onpointerup = stopDrag;
    header.onpointercancel = stopDrag;
  }
  ```
